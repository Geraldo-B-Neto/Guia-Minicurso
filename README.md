## 📌 Sobre o projeto

Este repositório contém um **modelo de portfólio pessoal**, desenvolvido como atividade prática do minicurso **HTML e CSS na Prática**, realizado no contexto da **Semana Nacional de Ciência e Tecnologia (SNCT) 2026**.

O projeto foi pensado para pessoas que estão começando no desenvolvimento web. Ao longo da oficina, os participantes aprendem a estruturar uma página com HTML, estilizar seus elementos com CSS, organizar o layout com Flexbox, adaptar o conteúdo para diferentes telas e publicar o resultado com GitHub Pages.

> **Este é um projeto-base de aprendizagem:** textos, habilidades, projetos e cores podem — e devem — ser personalizados.

## 🎯 Objetivos

- Compreender a função do **HTML** e do **CSS** na construção de páginas web.
- Utilizar elementos HTML semânticos para organizar o conteúdo.
- Aplicar cores, fontes, espaçamentos, botões e cards com CSS.
- Organizar componentes utilizando **Flexbox**.
- Introduzir o conceito de **design responsivo** com media queries.
- Personalizar um portfólio pessoal.
- Conhecer o GitHub e publicar um site estático com **GitHub Pages**.

## ✨ Funcionalidades

- Menu de navegação com links para as seções da página.
- Seção de apresentação pessoal.
- Seção **Sobre mim**.
- Lista de habilidades apresentada em cards.
- Área para exibição de projetos.
- Link de contato por e-mail.
- Layout adaptável a diferentes tamanhos de tela.

## 🚀 Como executar localmente

1. Baixe o projeto pelo botão **Code → Download ZIP** no GitHub ou clone o repositório.
2. Extraia os arquivos, se necessário.
3. Abra a pasta no **Visual Studio Code** ou em outro editor de sua preferência.
4. Abra o arquivo `index.html` no navegador.

Opcionalmente, utilize uma extensão como **Live Server** para visualizar as alterações durante o desenvolvimento.

## 🎨 Como personalizar

### Alterar informações pessoais

Abra o arquivo `index.html` e substitua os dados de exemplo:

- Nome e apresentação inicial.
- Texto da seção **Sobre mim**.
- Habilidades e competências.
- Nomes e descrições dos projetos.
- Informações de contato, caso deseje divulgá-las.

### Alterar a aparência

Abra o arquivo `style.css` e experimente modificar propriedades como:

```css
body {
    background-color: #0f172a;
    color: #f8fafc;
}

h1 {
    color: #a78bfa;
}

.botao {
    background-color: #7c3aed;
}
```

Você também pode explorar `padding`, `margin`, `border-radius`, `gap`, `display: flex` e as regras `@media` para ajustar o layout.

## 🌍 Como publicar no GitHub Pages

1. Crie um repositório **público** no GitHub, por exemplo, `meu-portfolio`.
2. Envie `index.html`, `style.css` e os demais arquivos do projeto para a **raiz** do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`.
6. Clique em **Save** e aguarde a publicação.
7. Acesse o endereço indicado na seção Pages.

O endereço normalmente terá o formato:

```text
https://SEU-USUARIO.github.io/meu-portfolio/
```

Substitua `SEU-USUARIO` pelo nome da sua conta. Se utilizar outro nome para o repositório, ajuste também o endereço.

> A publicação pode levar alguns minutos. Se o site não abrir imediatamente, confira o andamento em **Settings → Pages** ou **Actions**.

Documentação oficial: [GitHub Pages](https://docs.github.com/pt/pages).
